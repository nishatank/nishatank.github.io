# Seeker for Scenes
Chasing dreams. Making memories.

A responsive static journal for Nisha and Priya. This folder preserves the existing portfolio at the repository root.

Edit shared sections in index.html, design in style.css and journal records in content.js. Article pages are in stories/. When changing an article, update its content.js record and matching HTML page together.

This is a static starter, not WordPress or a CMS. Six articles are clearly labelled previews. Replace illustrative Unsplash photographs and draft content with original stories before a finished public launch. Google hosts the Manrope font files; Unsplash hosts the moodboard images. No analytics, comments or email collection are installed.

The brand logo is intentionally a neutral wordmark while three new logo directions are under review. Rejected illustrated artwork is not included.
